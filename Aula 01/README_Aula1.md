# Aula 1 - Introdução ao Python 🐍

## Conteúdo
- Primeiros passos: `print("Olá, mundo!")`
- Variáveis e tipos de dados (string, int, float, bool)
- Operações matemáticas básicas (+, -, *, /, %, //, **)
- Estruturas condicionais (`if`, `else`)
- Estruturas de repetição (`for`, `while`)
- Listas e iteração
- Funções (`def` e `return`)

## Objetivos
- Entender a sintaxe básica do Python.
- Executar operações simples e criar pequenos programas.
- Desenvolver lógica de programação inicial.

## Atividade Proposta
1. Crie uma variável com seu nome e idade.
2. Faça o programa imprimir: "Meu nome é X e eu tenho Y anos".
3. Crie uma lista com 5 números e calcule a soma deles.
4. Crie uma função que receba dois números e retorne a multiplicação.
